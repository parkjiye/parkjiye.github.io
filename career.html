경력기술서

연간방문객 600만 명 규모의 예매·결제 도메인에서 고객서비스 시스템을 개발·운영하는 3년차 백엔드 개발자입니다. 프로젝트 단위로 담당 업무와 성과를 정리했습니다.

롯데이노베이트

2023.05 — 현재

월드IS팀 · 고객서비스

롯데월드 및 계열 사업장의 티켓 예매·결제·연간회원 서비스를 개발·운영하는 팀.
연간 방문객 600만 명 규모의 예매 시스템(advticket.lotteworld.com)을 담당.

결제 시스템 개선 및 안정화

2025.09 — 2026.05

1) 통신사 할인/승인 프로세스 고도화

역할

  • 결제·취소 도메인 메인 개발자

업무

  • 기존 통신사 할인 + 주결제 승인 프로세스 불안정(브라우저의 localStorage에 저장 및 통신사 승인과 주결제 승인 프로세스 분리)
  • 통신사 할인 정보를 Redis에 저장 -> 저장된 정보를 바탕으로 통신사 승인 시 사용
  • 통신사 승인과 주결제 승인 프로세스 통합

2) 결제/취소 오류 등 간헐적 엣지 케이스 원인 규명 및 개선

  • 결제 오류 건수 월 100건 이상 → 10건 미만으로 90% 이상 감축
  • 통신사 가승인, 결제·취소 오류 등 간헐적 엣지 케이스 원인 규명 및 개선
  • 결제 수단 확장 프로젝트 리드

사용 기술

  • Java
  • Spring Boot
  • Redis
  • React
  • MSSQL

월드 차세대 전환 프로젝트

2024 — 2025.12

레거시 Spring/JSP 시스템을 차세대 아키텍처로 전환하는 프로젝트에서 고객서비스 파트 담당.

역할

  • 고객서비스 파트 담당 개발자

업무

  • 연간회원·강습·결제 시스템 메인 개발자로 개발 및 운영
  • 통합 웹티켓 프로세스 설계 및 개발
  • 웹티켓/지류티켓 등록 서비스 개발
  • 카카오 톡학생증 API 연동 설계·개발, 이후 톡사원증·틴카드·감면카드까지 확장 가능하도록 모듈화

사용 기술

  • Java
  • Spring Boot
  • JPA
  • JavaScript
  • React
  • MSSQL

신규 서비스 및 인프라 운영

2023.05 — 현재

업무

  • Spring Scheduler 기반 앱푸시 자동 발송 프로세스 구축 (배치 발송 + 행동 기반 발송 구조 설계)
  • 통신사 할인 인증/승인 프로세스 고도화 (레거시 리팩토링)
  • 레거시 소셜 로그인 시스템 API 업그레이드 및 고도화
  • OpenShift 기반 배포 환경에서 서비스 운영
  • 다양한 파트너사·조직과 협업하며 프로젝트 리딩, 요구사항 조율

사용 기술

  • Spring Boot
  • JPA
  • MSSQL
  • OpenShift
  • Jenkins
  • GitLab
  • Grafana

  • 권한 신청/승인/반려 시스템 구현
  • 역할 기반 접근 제어(RBAC) 및 사용자 행위 로깅 기능 개발
