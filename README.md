# parkjiye.github.io

박지예의 이력서 사이트입니다. Apple 스타일의 미니멀한 디자인으로 제작되었습니다.

- 배포 URL: https://parkjiye.github.io
- 별도 빌드 과정 없이 순수 HTML/CSS로 작성되어 있어 `index.html`만 수정하면 바로 반영됩니다.

## 구성

- `index.html` — 페이지 구조 및 콘텐츠 (자기소개, 경력, 기술 스택, 학력/자격증/대외활동)
- `style.css` — 디자인 (시스템 폰트, 여백, 라운드, 그림자, 라이트/다크 모드 대응)

## 콘텐츠 채우기

현재는 플레이스홀더 텍스트로 채워져 있습니다. `index.html`에서 아래 항목들을 실제 내용으로 교체하세요.

- 헤더의 연락처 링크 (GitHub은 연결되어 있고, Blog/LinkedIn은 `#`로 비어있음)
- About Me 문단
- Experience의 회사명/직급/기간/성과
- Skills의 기술 목록
- Education & Activities의 학력/자격증/대외활동

## 로컬 미리보기

파일을 더블클릭해서 열거나, 터미널에서:

```bash
open index.html
```

`main` 브랜치에 push하면 GitHub Pages가 자동으로 반영합니다 (수 분 소요).
